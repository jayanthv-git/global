# Scope deliberately cut

- Real questionnaire administration until approved wording, response options, Arabic versions, licensing and local clinical review are supplied. The explicitly labelled placeholders exercise the software loop only.
- Real staffed crisis response, emergency dispatch, identity/contact collection, phone calls and clinical decisions. The queue is an operational simulation without patient records. No real human will contact someone from this prototype.
- Real booking, provider integration, external email, WhatsApp/SMS, push notifications and scheduled background follow-up delivery. Due-date prompts are in-app only while the server is running.
- A statistically validated reliable-change index or EWMA. The requested simple configurable difference check is implemented and marked UNVERIFIED.
- Production authentication, account recovery, UAE PASS, multi-tenant clinician administration, employer access, regulatory certification, security audit, production key rotation, retention/deletion policy and health-record/Malaffi integration.
- Offline writes with the backend stopped. Sensitive records are never stored in a service-worker cache or replay queue. The local server can run without internet after setup.
- Real demographic fairness claims, clinical outcomes, waiting-time reduction, or competitor-gap claims. The dashboard demonstrates a pipeline on a fixed synthetic cohort only.
- Arbitrary aggregate filters, demographic cross-tab intersections and exports: a fixed set of six grouping choices limits small-cell and differencing exposure. Metrics have no participant-level endpoint.
- Chatbots, LLMs, passive monitoring, diagnosis, automated therapy, blockchain and deep learning: neither required nor included.

All requested core software paths are implemented. These exclusions keep the local demo small enough to explain and verify; they are not hidden behind mock-success buttons.
